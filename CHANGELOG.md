# Changelog

## 1.0.0 - 2026-07-26

- Tiny AgenC 1.0.0 includes a complete character-level autoregressive
  transformer and handwritten backward pass in C11.
- Added a 19-chapter book, three appendices, and a 16-stage every-line
  build track.
- Added independent forward witnesses, finite-difference checks,
  whole-model connectivity tests, OpenMP invariance checks, hostile
  checkpoint fixtures, CLI smoke tests, sanitizers, and CI.
- Introduced deterministic scene-level validation splitting and a
  matched add-one bigram baseline.
- Introduced checksummed TAGC version 1 checkpoints with resource
  preflight and atomic replacement.
- Bundled a measured 815,360-parameter checkpoint and reproducible
  training and validation evidence.
- Repaired and mechanically checked the book's terminal diagrams.
- Added portable default builds, configuration-aware object rebuilding,
  complete staged installation, and a central evidence manifest.
